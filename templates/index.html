How it works

Four simple steps

From a PDF resume to a personal learning plan in seconds.

STEP 1

Upload resume

Drop a text-based PDF. It is read in memory and never stored.

STEP 2

Skills extracted

extract_skills() finds listed skills. You can edit the result.

STEP 3

Roles recommended

recommend_roles() ranks roles with scores from the chosen model.

STEP 4

Skill gap

See matched and missing skills, with a priority learning list.
